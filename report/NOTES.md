# Presentation notes

The original presentation is preserved as `presentation.pdf`.

It reports a best validation accuracy of 88.92% (12,125/13,636 at epoch 15) with early-stopping patience 6. The final notebook supplied with the project records 88.80% (12,109/13,636 at epoch 11) with `PATIENCE = 8`.

Because the checkpoint and executable ablation code associated with 88.92% were not retained, this repository treats the notebook's traceable 88.80% result as the primary result. The pooling and FC-head ablation numbers in the presentation are retained as reported results, not as fully reproducible experiments in the current repository.
